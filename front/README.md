# Store frontend

واجهة المتجر والسلة ونموذج بيانات العميل.

شغّل `npm run dev` من هذا المجلد. شغّل الخادم أولاً من `../back` باستخدام `npm start`؛ إعداد Vite يمرر طلبات `/api` إلى الخادم على المنفذ 3001.

لإنشاء نسخة إنتاجية شغّل `npm run build` هنا، ثم شغّل `npm start` من مجلد `../back` ليقدم الواجهة المبنية وواجهات الطلبات.
