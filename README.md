# متجر كمالياتي

## تقسيم المشروع

- `front`: واجهة المتجر والسلة ونموذج بيانات الزبون.
- صفحات منفصلة لتفاصيل المنتج `/product/:id` والسلة `/cart`، بتصميم كمالياتي.
- `back`: API بـExpress مقسّم إلى `config` و`controllers` و`models` و`routes` و`utils`، بنفس تنظيم باك Baz Shop.
- MongoDB Atlas يخزن المنتجات والسلال والطلبات.
- صفحة الإدارة في `/admin` لتسجيل الدخول وإدارة المنتجات ومتابعة الطلبات وتحديث حالتها.

## ربط Atlas والتشغيل

جهّز `back/.env` من `back/.env.example` محلياً. استخدم قيم الاتصال التي يعطيها Atlas؛ إذا كان DNS يمنع SRV فاستخدم Standard connection string بعناوين العقد الثلاثة. لا ترفع `.env` إلى Git ولا ترسل بيانات الدخول في المحادثة. تعليمات الإعداد موجودة في `back/README.md`.

في `back/.env` عيّن كلمة مرور إدارة قوية لا تقل عن 12 حرفاً محلياً و16 حرفاً في الإنتاج، و`JWT_SECRET` عشوائياً لا يقل عن 32 حرفاً. استخدم قيماً جديدة في خدمة الاستضافة، ودوّر كلمات المرور التي ظهرت في لقطات الشاشة قبل النشر.

من هذا المجلد شغّل `npm run dev` للتطوير. لنسخة الإنتاج شغّل `npm run build` ثم `npm start`. أول تشغيل يضيف منتجات المتجر الحالية إلى قاعدة `kamaliyati` فقط إذا كانت مجموعة المنتجات فارغة.

## النشر كخدمة واحدة

- ملف `render.yaml` يجهّز Web Service على الخطة المجانية كبداية.
- أضف `MONGO_URI` و`ADMIN_USERNAME` و`ADMIN_PASSWORD` و`JWT_SECRET` كمتغيرات سرية في لوحة Render، ولا ترفع `back/.env`.
- الواجهة تُخدم من الباك بعد البناء، لذا يستخدم المتصفح نفس أصل النشر لطلبات `/api`.
- صور المنتجات المرفوعة تُخزن محلياً في `back/uploads`. تخزين الخطة المجانية مؤقت؛ قبل استخدام الإدارة لرفع صور جديدة على الإنتاج، انقل الصور إلى خدمة تخزين ملفات أو اختر خدمة بخاصية قرص دائم.
